Eaglercraft

Welcome to Eaglercraft.
This project lets you run the game in a browser-based format with a simple setup process. Follow the steps below to get started.
Download

Download the EaglerCraft_1.12_Offline_Download.zip file.
Save it to your computer.
Extract the ZIP file into a folder.

#Setup

Open the extracted folder.
Look for the main .html file or launch file.
Open it in your browser.
Wait for the game to load.

#How to Use

Use the main menu to start the game.
Choose your settings if needed.
Begin playing.

Steps
Step 1: Download the File

Step 2: Extract the ZIP

Step 3: Open the Launcher

Step 4: Start Playing

#Tips

Keep all files in the same folder.
Do not rename important files.
Use a modern browser for the best results.

#Troubleshooting

If it does not open, try another browser.
If the screen stays blank, refresh the page.
If files are missing, re-extract the ZIP file.
